# 动态指导助手

一个用于 SillyTavern 酒馆助手（JS-Slash-Runner / TavernHelper）的动态世界书脚本。

作者可以把完整的剧情阶段、重要物品、地点规则和秘密写在一个角色绑定世界书条目中。脚本会禁用完整来源条目，每次生成时只向 AI 注入当前有效内容。

当前发布版本：**v1.2.0**

## 推荐安装方法

下载并导入：

```text
酒馆助手脚本-动态指导助手-在线版.json
```

在线版的脚本正文只有一行：

```js
import 'https://gcore.jsdelivr.net/gh/PlayerAlex/sillytavern-dynamic-guide@v1.2.0/index.js';
```

如果 `gcore.jsdelivr.net` 在你的网络中无法访问，可以改用：

```js
import 'https://cdn.jsdelivr.net/gh/PlayerAlex/sillytavern-dynamic-guide@v1.2.0/index.js';
```

固定版本地址不会随着仓库后续更新自动改变，角色卡作者可以在测试完成后稳定发布。

## 在酒馆里安装

1. 安装并启用酒馆助手 JS-Slash-Runner / TavernHelper。
2. 打开酒馆助手脚本管理页面。
3. 导入 `酒馆助手脚本-动态指导助手-在线版.json`。
4. 确认脚本已启用。
5. 打开要制作的角色聊天。
6. 点击左下角魔法棒，在菜单中打开“动态指导助手”。
7. 在独立管理页里选择角色世界书和剧情指导条目，然后点击“绑定所选条目”。

如果不想联网加载，可以导入：

```text
酒馆助手脚本-动态指导助手-离线版.json
```

离线版包含完整代码，功能与在线版相同。

## 自己创建一行 import 脚本

也可以在酒馆助手中新建脚本，把脚本正文替换为：

```js
import 'https://gcore.jsdelivr.net/gh/PlayerAlex/sillytavern-dynamic-guide@v1.2.0/index.js';
```

保存并启用后，远程脚本会在左下角魔法棒菜单中注册一个“动态指导助手”入口。绑定、状态查看、上一段、下一段和重置都集中在独立管理页中。

从 v1.1 升级时，v1.2 会自动清理旧版遗留的五个脚本按钮。重新导入在线版 JSON 也会同步清空旧按钮配置。

## 世界书写法

在角色绑定世界书中创建一个条目，例如“动态指导”，然后写入：

```text
【内容：雨夜初遇】

什么时候出现：
游戏开始时

告诉AI：
{{char}}第一次在雨夜遇见{{user}}。
这一阶段两人需要进行第一次正式交谈。
暂时不要透露地下室的秘密。

什么时候消失：
两人完成第一次正式交谈。


【内容：地下室的声音】

什么时候出现：
上一段结束后

告诉AI：
夜深后，地下室会传来断续的敲击声。
{{char}}知道声音不正常，但不愿立刻说明真相。

什么时候消失：
{{user}}决定调查地下室。


【内容：进入地下室】

什么时候出现：
上一段结束后

告诉AI：
两人正式进入地下室。
现在可以逐步揭示地下室的秘密。

什么时候消失：
地下室事件结束。
```

不填写“类型”时，内容块会被当成主线，并按照书写顺序推进。

## 临时物品和规则

```text
【内容：蚀月戒指】

类型：重要物品

什么时候出现：
《进入地下室》正在进行时

告诉AI：
戒指能看见灵体。
副作用是佩戴者会逐渐分不清死人和活人。

什么时候消失：
《进入地下室》结束时
```

填写“类型”后，这一块会作为附加内容跟随主线，不占用主线进度。

## 工作方式

- 完整原文一直保存在世界书中。
- 来源条目绑定后会被禁用，避免完整内容被原生世界书直接发送给 AI。
- 每次生成只发送当前主线和当前有效的附加内容。
- AI 判断当前目标已经完成后，会输出隐藏完成标记并推进到下一段。
- 每个聊天独立保存进度。
- 判断错误时可以在魔法棒菜单的管理页中使用上一段、下一段和重置修正。
- 不需要额外的大模型 API。

## 文件说明

- `index.js`：供 jsDelivr 加载的完整运行代码。
- `酒馆助手脚本-动态指导助手-在线版.json`：推荐给普通用户导入。
- `酒馆助手脚本-动态指导助手-离线版.json`：不依赖远程加载的完整版本。
